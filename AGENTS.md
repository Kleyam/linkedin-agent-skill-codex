# LinkedIn Agent Workspace

Este repositório contém skills para criação e gestão manual de conteúdo no LinkedIn.

Regra principal:
- Nunca publicar, enviar, agendar ou interagir automaticamente no LinkedIn.
- O usuário deve revisar e executar manualmente todas as ações.

Use as skills em .agents/skills/ quando o usuário pedir:
- criação de post
- comentário em publicação
- resposta a comentários
- otimização de perfil
- planejamento semanal
- humanização de texto
- carrossel
- reaproveitamento de conteúdo
- DM / convite
- triagem de inbox
- auditoria

Arquivos locais:
- leia `linkedin/voice.md` antes de escrever
- use `linkedin/plan.md` para calendário
- use `linkedin/log.md` para histórico e auditoria
- salve rascunhos em `linkedin/drafts/`

Regras:
- nunca inventar números, clientes, métricas ou resultados
- se faltar dado real, usar `{{your number}}` e avisar
- usar a skill `li-human` antes de mostrar qualquer texto final
- não prometer que o texto é indetectável
- o usuário publica manualmente tudo
